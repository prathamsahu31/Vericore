# Project Screenshots & Visual Evidence

This directory contains high-resolution screenshots and visual documentation of the **Vericore** platform for the SIH 2026 evaluation committee.

## Recommended Naming Conventions

Save your interface screenshots and prototype visuals in this folder using descriptive prefixes:

- `01_dashboard_overview.png` — Main procurement officer dashboard showing active tenders.
- `02_nit_clause_extraction.png` — Clause extraction and requirement confirmation checklist screen.
- `03_bidder_comparison_matrix.png` — Multi-bidder compliance matrix and scoring breakdown.
- `04_evidence_ledger_drilldown.png` — Exact bounding-box highlight on original bidder PDF document.
- `05_cross_document_anomaly.png` — Cross-document contradiction alert (e.g. GSTIN vs PAN mismatch).
- `06_external_register_lookup.png` — GSTN, MCA21, and Udyam multi-portal verification status.
- `07_officer_decision_ledger.png` — Officer review gate with reason capture and hash-audit event recording.
- `08_printable_evaluation_report.png` — Official exportable tender committee summary report.
